# 个人主页美化与功能增强 — 设计文档

日期：2026-05-31
方向：A · 精炼纸感（保留暖纸色 + 衬线学术底子）+ 高级感打磨

## 目标

在不改变现有「数据驱动」架构（内容在 `editable/site-data.js`，渲染在 `assets/render.js`，样式在 `assets/styles.css`）的前提下，提升主页的视觉质感，并加入四个实用功能。

## 视觉打磨（CSS 为主）

- **配色**：保留暖纸色底子，强调色调整为更克制高级的蓝灰；卡片表面加柔和分层阴影。
- **字体与留白**：收紧标题字号节奏、优化行高与字距，章节间距更舒展。
- **微交互**：链接/卡片平滑过渡、悬停下划线动画、章节滚动渐入（IntersectionObserver）、细腻的 focus 焦点环。

## 四个功能

1. **亮/暗切换**：`<html data-theme>` 控制；暖色暗调（非纯黑）；右上角按钮；`localStorage` 记忆；首访跟随系统 `prefers-color-scheme`。
2. **滚动高亮导航**：IntersectionObserver 自动高亮左栏当前章节。
3. **复制邮箱 + 返回顶部**：点邮箱一键复制并弹出「已复制」轻提示；右下角滚动后浮现返回顶部按钮。
4. **中英文切换**：顶部语言按钮；`localStorage` 记忆；切换后重渲染。

## 数据结构调整（关键）

- `site-data.js` 文字字段由纯字符串改为 `{ zh, en }`。
- `render.js` 增加 `pick(field, lang)`：字段是对象则取当前语言（缺失时回退 `en` → `zh`）；是纯字符串则原样使用 —— 向后兼容，可逐步翻译，不会因漏翻报错。
- 现有英文内容补一份中文译文作为初稿，用户后续可在 `site-data.js` 直接润色。

## 改动文件

- `assets/styles.css` — 高级打磨 + 暗色主题 + 新组件样式（切换钮、轻提示、返回顶部、激活导航）
- `index.html` — 主题/语言切换钮、返回顶部按钮、提示容器的挂载点
- `editable/site-data.js` — 双语结构 + 中文初稿
- `assets/render.js` — 语言感知渲染、主题/语言切换、滚动高亮、复制邮箱、返回顶部

## 测试

- 本地用浏览器打开 `index.html`，逐项验证：亮/暗切换并刷新保持、语言切换并刷新保持、滚动时导航高亮、点邮箱复制并出现提示、滚动后返回顶部按钮出现并可用。
- 验证窄屏（< 920px）布局不破。
- 验证旧的纯字符串字段仍能正常渲染（向后兼容）。

## 非目标（YAGNI）

- 不做简历 PDF 导出、博客最新文章抓取（本次未选）。
- 不引入构建工具或框架，保持纯静态 + vanilla JS。
