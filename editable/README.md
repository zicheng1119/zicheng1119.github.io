# 可编辑目录

此目录是简历站点的主要编辑区域。

## 文件说明

- `site-data.js`
  - 页面的主要内容源
  - 在此编辑你的姓名、简介、链接、章节、作品、动态和页脚
- `overrides.css`
  - 可选的个人 CSS 覆盖文件
  - 如果你想调整颜色、间距或组件样式而不修改基础样式表，使用此文件
- `images/`
  - 将你的头像或其他个人图片放在此处

## 推荐工作流

1. 编辑 `site-data.js`
2. 本地预览
3. 如果需要，在 `overrides.css` 中添加小的视觉修正
4. 提交并推送

## 何时需要编辑其他文件

- `index.html`
  - 仅当你想更改页面骨架时
- `assets/styles.css`
  - 仅当你想更改共享的基础设计系统时
